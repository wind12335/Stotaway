# AG 分组与临时复制：单卡就绪数据原型（2026-11-14）

A800-SXM4-80GB，BF16；12 个 AG 形状，预设 8 个 peer 的输入均在本卡就绪，模拟 rank=3 的 shift 顺序。`copy_1` 为逐 peer 临时复制加 GEMM；`direct_N` 直接读取本地连续输入，至多把 N 个连续 peer 的行合成一个 GEMM。含本地 rank GEMM；所有模式与完整 GEMM 数值对照通过。每模式预热 4 次、随机交错 8 组、每组 16 连发。比值为 copy_1 耗时 / 对应模式耗时。

此原型的所有输入均已就绪且在本地，直接读取和分组没有模拟实际跨 rank 传输、等待、信号、ACK、带宽争用或重叠；这些数值不是多卡 DX 算子 speedup。分组因 rank 自身排除和 shift 顺序形成连续段，rank=3 时 direct_4/direct_8 均为 [4,5,6,7] 与 [0,1,2]，不保证 8 个 peer 一次 GEMM。单卡结果表明该方案值得进一步开发，但各模式的选优需以真实分布式数据确认。
