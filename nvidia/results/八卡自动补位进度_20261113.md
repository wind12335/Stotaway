Llama 的 Triton-distributed 自动计划每 rank 命中：`qkv` AG 使用 Triton-distributed、`proj` RS 使用 DX、`fc1` AG 使用 stock、`fc2` RS 使用 DX，各 3760 次。其 TTFT 为 1696.4 ms，2M TTFT 为 3881.3 ms，16 请求总耗时为 27357.1 ms；各自对 stock 为 1.152×、1.132×、1.150×。纯 Triton-distributed 对应 TTFT 为 1869.0 ms、2M TTFT 为 4228.8 ms、16 请求总耗时为 30209.4 ms；自动方案分别为 1.102×、1.090×、1.104×。每组为独立运行。

FlashOverlap 已覆盖 33/33 个 RS 形状，其中 23 点为原生内核计时，10 点为包含布局转换的派发计时；其余四组算子矩阵各为 99/99。Syncopate 和 FlashOverlap 的指定算子派发结果、完整算子表和自动方案数据见 [算子结果表](单机8卡多后端算子结果_20261113.md) 与 [端到端结果表](单机8卡端到端与预测器结果_20261113.md)。

Syncopate 与 FlashOverlap 自动方案在所测模型中均选择 AG 为 stock、RS 为 DX；外部后端预测使用 FP16 数据、DX 预测使用 BF16 数据。FlashOverlap FP16 原先 10 个算子缺口已通过实际输出直接对照并完成派发计时，其中 405B 最大形状采用单分组候选，未做完整调优。
