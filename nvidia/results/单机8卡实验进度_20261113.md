# 单机 8 卡实验进度（2026-11-13）

设备为 8× A800-SXM4-80GB，TP=8。算子矩阵使用全局 M=8192、16384、32768，AG 每卡输入 M 分别为 1024、2048、4096。stock 为串行 AG+GEMM 或 GEMM+NCCL RS，每个方法的 speedup 均使用其对应 stock 计时。

99 个多模型、投影、形状的结果和实时进度见 [单机 8 卡多后端算子结果](单机8卡多后端算子结果_20261113.md)。Async-TP 和 DX 各有 99 个点，Triton-distributed 的 AG 已完成 66/66、RS 已完成 33/33；Syncopate 正在扩展 FP16 多模型矩阵，FlashOverlap 的其余 RS 点已排队。DX 直接复用已有八卡结果。

对新测 Async-TP，66 个 AG 点均超过 1×（ag_gu 中位 1.217×、ag_up 中位 1.394×），33 个 RS 点低于 1×（中位 0.921×）。既有 DX 的 33 个 RS 点中 32 个超过各自 stock。两者来自独立批次，各自除以各自的 stock；后续在实际组合中测量补位净收益。

预测器对 99 个 Async-TP 点做按模型留出，stock 与 Async-TP 二选一为 96/99（96.97%）；其中 AG 65/66，RS 31/33。详细数据包括 3 个错选点和所有预测值，见 `/root/data/stowaway-nvidia/results/tp8_async_predictor_lomo_20261113.json`。本项是算子级开发数据评估；三候选补位与端到端结果尚待实验。

既有 8 卡 Qwen3.6-27B 64 层文本配置训练数据、Llama3-70B 80 层真实权重推理数据保留在 [端到端与预测器结果表](端到端与预测器结果表.md) 与 [原表对照](单机8卡原表对照_20261111.md)，不会因本次扩展后端而删除。

8 卡三候选执行检查通过，每 rank 各执行两次 stock、Async-TP 和 DX；vLLM 合成模型的 Async-TP 及 Async-TP + DX 补位也已通过 8 rank 检查。

Qwen3.6-27B 的 stock、Async-TP、Async-TP+DX 训练均已完成，整步 speedup 分别为 1.000×、1.017×、1.073×；Llama3-70B 的三臂推理也已完成，逐项数值见 [本次端到端与预测器表](单机8卡端到端与预测器结果_20261113.md)。
