# 端到端与预测器结果表（NVIDIA A800，单机 8 卡）

与 BW1000 原表同载具、MBS 和全局 batch 的单机 8 卡实验正在进行，逐臂结果与失败状态见 [单机 8 卡原表对照](单机8卡原表对照_20261111.md)。本文件下方保留此前不同 batch 的诊断结果，不能与原表同配置数值直接混算。

加速比 = 同一载具的原版整步时间 / 候选整步时间；绝不跨不同模型、后端或配置相比。训练使用 mock data，随机初始化，BF16，TP8+序列并行，full 重算，MBS1/GBS1；每臂一个独立进程。以下数据为短跑、单轮，后 3 步中位，不是原 BW1000 表中 14–18 步、ABAB 两遍的正式口径。

### A800 调优后，12 步两轮（seq4096 / MBS1）

对行投影使用 rank 相对置换发送序并合并 RS 确认内核；列投影保持原版 NCCL。两个开关为 `STOWAWAY_DX8_SCHEDULE=shift STOWAWAY_DX8_BATCH_ACK=1`，默认关闭。顺序 stock→DX→stock→DX，独立进程；12 步去掉前 3 步，每次取其余 9 步中位。两臂同 local 实验 hybrid spec、随机权重和 mock data。

| 臂 | 第一遍 / 第二遍 ms | 两遍中位 ms | 相对 stock |
|---|---:|---:|---:|
| stock | 1271.1 / 1266.8 | 1268.95 | 1.000× |
| 优化行 DX | 1241.8 / 1252.0 | 1246.90 | **1.018×** |

两轮配对分别为 1.024× 和 1.012×；DX 每 rank 3072 次行命中、0 列命中，两臂无跳步/NaN。词表修正的 Qwen 4 层、seq4096 首步八 rank 全部捕获梯度，`rtol=0.02, atol=0.002` 下失败张量为 0，报告 `/root/data/stowaway-nvidia/results/tp8_20261111/qwen36_hybrid4_grad_shift_batchack_diff.json`。该门槛不覆盖 64 层长训练及真实权重，性能也尚未对 TE/FLUX 等强基线作同配置对照；因此属于初步结果。日志 `tp8_qwen36_tune12_{stock,dx}_r{0,1}_20261111.log`。

同口径单轮消融：空对照 1266.6 ms（各 rank 命中 0，且不预分配全部 DX buffer）；固定顺序 + 合并 ACK 为 1332.2 ms；置换顺序 + 原 ACK 为 1245.6 ms。置换 + 合并 ACK 两轮中位 1246.9 ms，对空对照为 1.016×。消融尚未交错复测；从现有数据只能说置换顺序与收益相关，不能声称合并 ACK 对整步产生确定收益。

### 前向和反向行 DX，两轮（seq4096 / MBS1）

同一窗口 base→DX→base→DX；64 层文本配置、随机初始化和 mock data，每臂 12 步，去前 3 步取中位。DX 同时接管 o_proj/fc2 的前向 GEMM+RS 和反向 AG+dgrad；独立 RS 启用 128 MB 门槛，但这个配置每个 rank 的独立 RS 命中为 0，不能把它说成已覆盖独立 RS。

| 臂 | 第一遍 / 第二遍 ms | 相对同遍原版 |
