# vLLM 结果表（NVIDIA A800 单机 8 卡，Llama3-70B）

真实权重，BF16，vLLM 0.11，TP8，eager；自然文本输入，温度 0，单请求。每种输出长度各 4 个提示，2 次预热；计时包含调度、prefill、采样及 decode，不含加载和分词。加速比 = stock / 候选。当前每臂仅一遍，不是原 BW1000 表中 ABAB 两遍的统计口径。

## 3. 长 prefill 压力测试，M=16384

原始模型最大上下文为 8192，本测试以 `VLLM_ALLOW_LONG_MAX_MODEL_LEN=1` 强制覆盖，只用于性能诊断；提示哈希逐项一致。

| 臂 | 1 token ms | 32 token ms | 对原版（1 / 32） | 与原版完整输出一致（1 / 32） |

| stock | 1959.069 | 3032.154 | 1.000× / 1.000× | 基准 |
| stock_sp | 1906.255 | 2996.409 | 1.028× / 1.012× | 1/4 / 0/4 |
| dx_col | 2036.410 | 3125.319 | 0.962× / 0.970× | 0/4 / 0/4 |

两个 SP 臂的测量阶段每 rank 均命中 8 次。输出差异在 SP 原版中已出现，原因未定位，因此不能宣称这些候选通过正确性门槛。原始结果文件为 `/root/data/stowaway-nvidia/results/tp8_20261111/vllm_llama70_*_m16384.json`。
