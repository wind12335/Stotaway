## 已确认的共同性能变量

1. **形状与 payload**：M/K/N 影响 GEMM 波数、通信字节数和尾部；不能只按 M 设静态阈值。
2. **分块和 wave**：更多 chunk 增加重叠机会，也增加信号、等待、launch 或 GEMM 分块损耗。FlashOverlap 和 Syncopate 都把它作为核心搜索维度。
3. **资源分配**：通信使用 copy engine、独立 stream、TMA 或 SM；可用 GEMM SM 数变化后，GEMM 波数和尾部变化。这个变量必须按后端建模。
4. **依赖方向**：AG 是通信生产数据、GEMM 消费；RS 是 GEMM 生产数据、通信消费。相同的 payload 在两种方向上不能共用一条代价曲线。
5. **信号与同步**：ready/ack、barrier、counting kernel、stream wait 和跨 rank ticket 次数会进入整步残差；信号数量和调用频次应保留在配置中。
6. **运行时回退**：Triton-distributed 的小 GEMM 可能直接走 cuBLAS＋NCCL，Flux 找不到配置时会回退到已注册 hparams。预测器必须记录实际路径，否则 baseline 名称会误导。

## 计划采用的模型输入

对一个固定后端，先构造可用性掩码，再计算：

`x = (M, K, N, dtype, payload, GEMM_G, collective_kind, world, topology, tile_count, wave_count, chunk_bytes, signal_count, compute_sms, comm_sms, forward_backward_role, fallback_path)`。

算子级模型预测该后端与 stock 的相对收益；整步模型按实际前向、重算、反向计数汇总，并以同批次整步观测拟合剩余项。缺少某个后端特征时，回退 stock 或该后端自己的保守默认值，不用其他项目的参数替代。

## 证据边界

- 四个项目尚未在 A800 上完成统一编译和同形状测试。
- 当前 A800 99 点只测 stock/DX；相对模型 16 连发探索结果为 88/99、1.062×，但有一个比 stock 慢超过 0.5%，不能替换既有安全模型。
- 单卡分块 GEMM 和 Qwen GDN padding 结果只能解释计算形状因素，不能代替多卡重叠实验。
- Qwen3.6 的 GDN `fc1/fc2` 与 MLP `fc1/fc2` 共用适配器名称；必须按真实 `(layer_type, M, K, N)` 区分。
- 目前最有依据的论文增量是“同一重叠后端内部的整步组合选择及其保守预测”，是否超过已有工作仍需统一 baseline 和样本外 E2E 证据。
