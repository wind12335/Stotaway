# 系统定位与可验证目标

用户最新确认的目标是：一次固定一个**已有重叠后端**，识别它在工作负载中优化不佳的调用点，判断我们自己的 DX 能否安全接替并产生收益，生成按调用点选择已有后端、DX 或 stock 的方案。DX 是系统自带的补位后端；不在同一方案中拼接 Flux、FlashOverlap 等多个外部后端。

例如以 Flux 为既有后端，方案可以保留部分 Flux 调用点，对适合的薄弱点使用 DX，剩余位置使用 stock；不会将 FlashOverlap 引入该 Flux 方案。上述是目标架构，当前代码尚未实现 Flux+DX 或其他外部后端+DX 的完整执行闭环。以下较早的数据仍按原实验口径保留，不能作为补位方案已验证的证据。

## 系统流程

1. 用户选择一个已有后端（如 Flux 或 FlashOverlap）与模型、设备、TP、dtype 和训练/推理场景；也可单独选择 DX 与 stock 进行基准对照。
2. 执行签名与可用性检查：解析该后端支持的算子、形状、前反向、布局和实际回退路径。当前已分析后端源码，但除 DX 外尚未接入和完成完整实测。
3. 对可用调用点分别预测已有后端、DX 与 stock 的代价；检查形状、通信语义、数值、布局、内存和同步兼容性，基于真实前向、重算和反向调用图评估组合、误差、整步交互与净成本。
4. 输出可执行计划及解释：每个调用点的开关、形状、计划版本、预测耗时与依据；对于不支持或未知的配置回退原版。调用点不完全等于四个名字，Qwen GDN 与 MLP 需要按形状/层类型区分。
5. 运行时按计划保留已有后端、启用 DX 补位或使用 stock；各 rank 对计划和运行上下文保持一致。DX 无法验证或无优势时不强行替换，选择仍由可用证据及整步收益决定。

## 1.00× 目标的数学含义

以同配置原版时间为分子，系统执行计划时间为分母：`speedup = T_stock / T_plan`。

- **≥1.00×**：不慢于原版；如果全部回退原版且没有额外系统开销，结果是 1.00×，这证明的是未退化，不是实际加速。
- **>1.00×**：该项有正加速。一个 MNK 的最优方法若真实慢于 stock，选择 stock 可以避免使用慢方法，但不可能凭选开关使该 MNK 获得严格 >1×。
- 计划预测快不意味着实测一定快。模型误差、额外初始化/调度、GPU 负载和时间抖动都可能造成预测与测量相反。要把“保证”写成结论，必须限定测量范围，并对实际计划与基线实测；本项目目前没有普遍理论保证。

## 已有证据和缺口

| 内容 | 实际数据 | 可以说什么 |
|---|---|---|
| A800 DX 前向算子，16 连发，99 点 | 原始预测器 29 点选 DX 且实测速度更快；70 点选 stock 按算子测量口径速度比等于 1；0 点低于 1 | 该数据集上的原始选择达到 ≥1.00×；70 点是回退，无正加速。只覆盖原版/DX 两种候选、当前测量口径。 |
| 相对收益探索模型 | 32 点选中后更快、66 点选择 stock、1 点实际更慢 | 平均更快，但尚不能声称每点 ≥1.00×。 |
| Llama3-70B 8 卡推理 | Plan 相对原版两遍单块 1.091×/1.088×、双块 1.077×/1.078×、16 请求 1.084×/1.084× | 已测真实推理配置有加速。不能据此推广所有长度、模型或后端。 |
| Qwen3.6 文本训练载具 | 前向行 DX 在 MBS1/2/4 两遍 >1；MBS8 0.993×/1.000×；完整行前后向 DX 的 MBS1 为 0.976×/0.975× | 部分训练路径有收益，也有回退。当前训练整步预测器尚未完成校准和 Plan/ALT E2E 实测，不能说所有训练 E2E ≥1。 |
| 用户给的 Flux/FlashOverlap 四卡算子记录 | 两种方法不同形状都存在赢和输 | 支持需要按同一方法的形状选用；该数据不是这些方法的模型 E2E 计划验证。 |

原始 99 点“回退”等于 1×是用同一个已测 stock 值作分子和所选 stock 值作分母的离线评估；真实端到端仍需测量计划接入本身的开销，不能把离线 1×当作运行时性能保证。

## 可作为论文主张的方向

研究目标可以写成：在给定外部重叠后端下，寻找它的低效调用点，并评估将这些位置替换成 DX 后，能否在计入规划、初始化与调度成本时进一步改善完整工作负载。实验须区分外部后端原始方案、其自身与 stock 的选择、DX/stock 方案，以及外部后端+DX+stock 补位方案。收益必须实测，不能假设所有点均正加速。

最终如果所有列入论文的配置都经真实计划实测满足 ≥1×，可写“在本论文测量的这些配置上均未低于原版”，列出范围与每格速度比；不应进一步推断所有可能形状或工作负载均有保证。若个别测量不足 1×，如实保留并分析，不以未实测回退结果替代。

DX 可作为系统提供的实际后端，但原 Stotaway 的论文一/论文二差异分析说明其基本票据/槽位协议继承先前工作。预测器的作用是选部署组合；DX 是否是独立新技术贡献，要依据实际新增机制和相关工作边界写清。
