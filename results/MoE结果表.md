# MoE 结果表（海光 BW1000，Qwen3-30B-A3B 形状，EP=8，TP=1）

- 形状：128 专家（每卡 16 个）、top-8、hidden 2048、专家 ffn 768；seq 4096，MBS 1，T = 每卡 token 数。
- 原版 = Megatron alltoall 派发器：先交换计数（count a2a），`.tolist()` 把计数读回 host（host 同步，CPU 要等 GPU），再变长 a2a，逐专家循环 GEMM，再反向 a2a。
- 我们 = 整层免 host 同步（sync-free，中文：CPU 从不等 GPU 读计数）：SM 直写派发到专家卡的对称堆（设备原子领槽位）→ 设备侧按本地专家排序 → 分组专家 GEMM（hipBLASLt grouped GEMM，设备侧计数，虚拟分组）→ 按 4 B 标签写回源 token → 加权求和。反向镜像。
- 加速比 = 原版 ÷ 我们（> 1 = 我们快）。

## 3. 预测器（MoE 侧，`planner/moe_plan.py`）

单卡、秒级：对给定专家形状和行数，实测原版逐专家循环与各虚拟分组大小 B 的分组 GEMM（前向 + 反向），选最快的；结果库 `planner/data/moe_plan.json`。

| 形状（每卡专家数 E / hidden / 专家 ffn / 行数） | 选择 | 对原版 |
|---|---|---|
| E16 / 2048 / 768 / 8192 | B = 2048 | 2.71× |
| E16 / 2048 / 768 / 32768（Qwen3-30B-A3B 车辆） | B = 2048 | 1.32× |
| E16 / 2048 / 768 / 65536 | B = 2048 | 1.20× |
| E16 / 4096 / 1536 / 32768 | B = 4096 | 1.21× |
| E32 / 7168 / 2048 / 32768 | B = 1024 | 1.09× |
| E8 / 4096 / 14336 / 16384 | B = 1024 | 1.01× |

B 的最优值随形状变（hipBLASLt 按网格形状选算法），所以按形状选而不是写死。
